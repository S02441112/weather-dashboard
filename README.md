# Weather Dashboard App 
- Python based
- FastAPI as logic 
- Uvicorn as web server

## Goal
- Use open-meteo API to query user given location to display relevent weather information
- Deploy on web server to be accessed by client devices

## Run program on server
- cd to ```~/Documents/Projects/weather-dashboard/app```
- run ```uv run uvicorn main:app --host 0.0.0.0 --port 8000```
